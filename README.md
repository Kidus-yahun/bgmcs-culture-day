# 🇪🇹 BGMCS Culture Day 2026 Celebration Portal

A modern web application designed for school senior batch students celebrating **BGMCS Culture Day** wearing authentic Ethiopian traditional clothes.

Built with **React 19**, **Tailwind CSS v4**, **Vite**, and styled with authentic Ethiopian cultural aesthetics.

---

## 🌟 Key Features

### 1. 📸 Authentic Cultural Photography Showcase
- **Real Photography**: High-definition, authentic photography of real Ethiopian models wearing traditional attire across the country.
- **Female & Male Look Switcher (360° Card Flip)**:
  - `👩 Female Look`: Handwoven dresses, Albaso/Shuruba braided hairstyles, gold jewelry, and draped Netela.
  - `👨 Male Look`: Traditional Shemma tunics, Surri trousers, and royal velvet Kaba capes.
- **Complete Cultural Coverage**:
  1. *Habesha Kemis & Netela* (Highlands / Pan-Ethiopian)
  2. *Oromo Wandabo & Caaccuu* (Oromia)
  3. *Tigray Tilfi & Zurya* (Tigray)
  4. *Wollo Festive Kemis* (Wollo / Dessie)
  5. *Harari Ashrafi Velvet* (Harar Jugol)
  6. *Dorze & Gamo Master-Woven Gabi* (Gamo / Chencha)
  7. *Men's Royal Velvet Kaba Cape & Tunic* (Ceremonial Royalty)
  8. *Welayta Traditional Striped Attire* (Welayta)
  9. *Sidama Fichee-Chambalaalla Traditional Attire* (Sidama)
  10. *Afar Traditional Sanafil & Shawl* (Afar)

### 2. 📝 Student Registration & Choice Conflict Tracker
- Students enter their name, email, chosen outfit, and can upload an optional sketch or photo.
- Resolves conflicts when too many students pick the same attire by encouraging fair regional distribution.

### 3. 🎡 Fair Distribution Lucky Wheel (Random Spinner)
- Fair random assignment with Web Audio synthesized tick sounds and win chimes.
- One-click **"Use this Outfit in Registration"** button to automatically fill the form.

### 4. 👥 Senior Roster & Dashboard
- Live directory of registered seniors with persistence in `localStorage`.
- Real-time registered senior counts and distribution metrics.

## 🚀 Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- `pnpm` (or `npm`)

### Installation & Development
```bash
# Install dependencies
pnpm install

# Start development server
pnpm run dev
```

### Production Build
```bash
pnpm run build
```
